# ⌨️ PulseMusic Keyboard Shortcuts

PulseMusic Desktop is fully navigable via keyboard shortcuts for fast, fluid audiophile and DJ playback control:

| Key Binding | Scope | Action |
| :--- | :--- | :--- |
| `Space` | Global | Play / Pause active track |
| `Ctrl + Right` / `Cmd + Right` | Global | Skip to next track in queue |
| `Ctrl + Left` / `Cmd + Left` | Global | Return to previous track |
| `Ctrl + Up` / `Cmd + Up` | Global | Increase volume by 5% |
| `Ctrl + Down` / `Cmd + Down` | Global | Decrease volume by 5% |
| `Ctrl + L` / `Cmd + L` | Global | Like / Unlike currently playing track |
| `Ctrl + K` / `Cmd + K` | Global | Focus Universal Search bar |
| `K` | Player | Toggle **Karaoke Mode** |
| `D` | Player | Open **CDJ Stem Deck** |
| `E` | Player | Open **10-Band Studio Equalizer** |
| `L` | Player | Open **Synchronized Lyrics View** |
| `F11` | Stage | Toggle Fullscreen Mode |
| `Escape` | Dialogs | Close active modal dialog / exit fullscreen |
| `1` – `4` | Stem Deck | Trigger Hot Cue 1, 2, 3, or 4 |
| `Left` / `Right` | Karaoke | Nudge lyric timing $\pm 250$ ms ($\pm 1.0$ s with Shift) |
| `0` | Karaoke | Reset lyric offset to default |
